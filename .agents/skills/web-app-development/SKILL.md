# Skill: Web App Development

## Usar cuando

- Se cree o modifique una aplicación web.
- Se trabaje con APIs.
- Se añadan controladores, endpoints o servicios.

## Proceso

1. Identificar framework y versión.
2. Revisar estructura existente.
3. Mantener controladores finos.
4. Validar entrada.
5. Colocar lógica en servicios.
6. Gestionar errores de forma uniforme.
7. Añadir logs estructurados.
8. Sugerir pruebas de endpoint o integración.

## Reglas

- No exponer detalles internos innecesarios.
- No devolver excepciones crudas al cliente.
- Usar códigos HTTP apropiados.
- Centralizar manejo de errores si el proyecto lo permite.
