# Skill: Testing Generation

## Usar cuando

- Se añada una funcionalidad.
- Se corrija un bug.
- Se migre código legacy.
- Se refactorice lógica de negocio.

## Proceso

1. Identificar comportamiento a proteger.
2. Buscar framework de tests existente.
3. Crear casos representativos.
4. Cubrir casos borde.
5. Cubrir errores esperados.
6. Evitar tests frágiles.

## Salida

- Tests propuestos o implementados.
- Casos no cubiertos.
- Verificación manual si no se pueden automatizar.
