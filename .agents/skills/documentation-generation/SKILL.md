# Skill: Documentation Generation

## Usar cuando

- Se cree un proyecto.
- Se cambie arquitectura.
- Se añada configuración relevante.
- Se prepare despliegue.
- Se cierre una migración.

## Proceso

1. Identificar audiencia.
2. Revisar estado real del proyecto.
3. Documentar ejecución, configuración y despliegue.
4. Documentar logs y gestión de errores si aplica.
5. Añadir decisiones técnicas relevantes.
6. Mantenerlo breve y útil.
