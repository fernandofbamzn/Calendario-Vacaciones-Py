# Workflow: Add New Feature

## Objetivo

Añadir una funcionalidad sin romper comportamiento existente.

## Pasos

1. Entender la funcionalidad solicitada.
2. Localizar zonas afectadas:
   - UI.
   - Lógica de negocio.
   - Acceso a datos.
   - Configuración.
   - Logs.
   - Tests.
   - Documentación.

3. Identificar patrones existentes.

4. Proponer plan de implementación.

5. Implementar en pasos pequeños.

6. Validar:
   - Caso correcto.
   - Casos borde.
   - Errores esperados.
   - Comportamiento existente.

7. Añadir logs relevantes.

8. Actualizar tests o proponer pruebas manuales.

9. Resumir:
   - Qué cambió.
   - Dónde.
   - Por qué.
   - Riesgos.
