# Workflow: New C# Project

## Objetivo

Crear una nueva aplicación C# mantenible.

## Pasos

1. Aclarar tipo de aplicación:
   - WPF escritorio.
   - Consola/CLI.
   - Web API.
   - Web app.
   - Worker service.
   - Librería.

2. Identificar:
   - Versión .NET objetivo.
   - Método de despliegue.
   - Base de datos.
   - Autenticación.
   - Integraciones externas.
   - Necesidades de testing.
   - Necesidades de logging.

3. Proponer arquitectura:
   - Estructura de proyectos.
   - Capas principales.
   - Dirección de dependencias.
   - Configuración.
   - Logging.
   - Gestión de errores.

4. Crear esqueleto mínimo funcional.

5. Añadir:
   - Configuración básica.
   - Inyección de dependencias si procede.
   - Logging.
   - Manejo de excepciones.
   - Primera funcionalidad.
   - Tests básicos.

6. Entregar:
   - Cómo ejecutar.
   - Cómo compilar.
   - Cómo probar.
   - Siguientes pasos recomendados.
