# Workflow: Review Pull Request

## Objetivo

Revisar cambios de código de forma técnica y útil.

## Pasos

1. Entender objetivo del cambio.
2. Revisar diffs por capas:
   - UI.
   - Negocio.
   - Datos.
   - Infraestructura.
   - Tests.
3. Detectar cambios de comportamiento no declarados.
4. Revisar nombres, estructura y consistencia.
5. Revisar gestión de errores.
6. Revisar logs.
7. Revisar seguridad y datos sensibles.
8. Revisar rendimiento.
9. Proponer mejoras accionables.

## Salida

Clasificar observaciones como:

- Bloqueante.
- Recomendado.
- Opcional.
- Pregunta.
