# Workflow: Release Checklist

## Objetivo

Preparar una entrega de aplicación C# con menor riesgo.

## Checklist

1. Compila en configuración Release.
2. Tests ejecutados.
3. Migraciones de base de datos revisadas.
4. Configuración de entorno revisada.
5. Logs activos y con nivel correcto.
6. Manejo de excepciones revisado.
7. Secretos fuera del repositorio.
8. Versión actualizada si aplica.
9. Notas de cambios preparadas.
10. Plan de rollback definido si aplica.
11. Prueba manual mínima realizada.
12. Validación de despliegue documentada.
